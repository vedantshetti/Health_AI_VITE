## 🚀 Quick Start (3 Steps)

```bash
# 1. Clone the repository
git clone https://github.com/vedantshetti/Health_AI_VITE.git

# 2. Install dependencies
cd Health_AI_VITE && npm install

# 3. Run the application
npm run dev
```

**Your app is now running at: http://localhost:5173** 🎉
